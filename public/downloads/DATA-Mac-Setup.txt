DATA for Mac: quick setup
========================
For DATA v1.0.62 (Apple Silicon and Intel DMG downloads)

1. COPY DATA INTO DOWNLOADS

   Double-click the downloaded .dmg. Select the DATA folder inside it and
   press Command+C. In Finder, choose Go > Downloads, then press Command+V.
   Wait for copying to finish. Do not replace an existing DATA folder.

2. OPEN TERMINAL

   Press Command+Space, type Terminal, then press Return.

3. PASTE THIS COMMAND AND PRESS RETURN

xattr -dr com.apple.quarantine "$HOME/Downloads/DATA" && bash "$HOME/Downloads/DATA/Start DATA.command"

   Copy the entire line, keeping $HOME and the quotes exactly as shown.
   If Terminal asks for access to Downloads, click Allow.
   Leave Terminal open while using DATA. The dashboard opens in your browser.

DATA is unsigned. This command clears the download block for the copied DATA
folder only, then starts DATA. Use it only for the official download you
trust. Python is included; no separate install is needed.

Next time: double-click Start DATA.command inside the same DATA folder.
Keep that folder; it stores your settings and conversations.

If you see "No such file or directory", check that the folder is named DATA,
is directly inside Downloads, and contains Start DATA.command.

If the browser does not open, visit:
http://localhost:7777
